## 形状・自己接触・糸

- 素足の写真で、母趾から小趾まで5本、かかとと足の内側の土踏まずを確認した。標準メッシュの足部で皮膚のスカラー場を評価した8,000点はすべて外側。判定は頂点サンプルで行った。[寸法の出典](../../docs/decisions/0009-leg-anatomy.md)
- 布の軸方向が逆転する頂点は417点。自己接触で外側へ動いた点は128点、最大累積補正量は1.34 mm。継ぎ目の重複点はこの集計から外した。[足首の自己接触](diagnostic-contact-ankle.png)・[膝裏の自己接触](diagnostic-contact-knee.png)
- 肌との隙間の範囲は足首0.61〜2.13 mm、膝裏0.60〜2.13 mm。同倍率のマクロ画像から算出した糸幅は太もも・足首ともに中央値18 px（約60.6 µm）。シェーダーに渡す共通の糸径は59.55 µm。[画像からの糸幅計測](macro-width.json)

## 性能と互換性

Linux x64、Chrome Headless Shell 151.0.7922.34、SwiftShader。WebGPU の検証エラーは0件。描画は1440 × 1080・DPR 1、ウォームアップ後90区間の全体が **10.47 FPS**、太ももの極限マクロが **4.08 FPS**。全体とマクロのフレーム時間の95%点は100.1 ms・266.7 ms。モバイル表示の Chromium エミュレーションで足部の切り替え、素足、設定シート、診断の切り替えを確認した。

| メッシュ | 計算点 | 三角形 | 布計算中央値 | 布計算95%点 |
| --- | ---: | ---: | ---: | ---: |
| 低 | 9,061 | 17,640 | 4.80 ms | 5.30 ms |
| 標準 | 22,945 | 45,120 | 9.10 ms | 12.80 ms |
| 高 | 43,165 | 85,272 | 15.70 ms | 20.00 ms |

布計算は準備後に6パスを送信し、GPUキューの完了を待つ時間を15回測った。CPU上の入力準備、読み戻し、描画は除く。改修版の iPhone Safari 実機の性能は未確認。改修前の iPhone 実測は[改修前の記録](../1a/README.md#iphone-safari-実機)を参照。

リポジトリルートで `node checks/1a/capture.cjs /path/to/chrome-headless-shell /path/to/cdn-cache` を実行すると撮影と計測を再現できる。糸幅は NumPy、Pillow、SciPy がある Python で `python3 checks/1a/measure-yarn.py` を実行して再測定する。[計測の生データ](result.json)
