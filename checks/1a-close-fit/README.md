## 寸法

| 計測項目 | 調整前 | 調整後 |

| 未着用時の足部基準径 | 39.8 mm | 36.8 mm |
| 未着用時の縦方向の材料長 | 830.3 mm | 797.3 mm |
| 脚の布の基準クリアランス | 0.60 mm | 0.42 mm |

| 着用時のつま先の前方への張り出し | 6.98 mm | 1.65 mm |

未着用時の寸法はプリセットと材料座標から読み取る。皮膚と布の前足部の幅は両メッシュの左右端、先端の余裕は両メッシュの最前端から求める。前足部の皮膚幅は93.68 mm。前回の前足部幅と張り出しは公開コミット `aa11b43` に現行の計測関数を接続して測った。

## 検証結果

- 標準メッシュの足部で調べた8,000頂点と16,320三角形の重心は、すべて皮膚のスカラー場で外側だった。重心の判定は足首付近の皮膚メッシュの接合部を避けて行った。低・標準・高のどの解像度も、スカラー場の値が−0.10 mmを下回る重心は0。低解像度の最小値は−0.049 mmだった。
- 固定計測線での肌から布までの隙間の変動幅は、足首0.40 mmから計測精度上の0 mm、膝裏0.71 mmから0.35 mmになった。幅が0 mmの足首の計測線にも固定の0.42 mmの隙間がある。
- 正対時の不透明度は太もも20.6%、足首24.0%、つま先補強53.1%。同倍率のマクロでの糸幅の中央値は両方18 px、約60.6 µm。[張力](diagnostic-tension.png)・[不透明度](diagnostic-opacity.png)・[糸幅](macro-width.json)

Linux x64、Chrome Headless Shell 151.0.7922.34・SwiftShader、1440 × 1080・DPR 1で全体7.01 FPS、極限マクロ3.34 FPS、WebGPU検証エラー0件。モバイル表示の Chromium エミュレーションで、足部、素足表示、マクロ、設定シートの操作を確認した。iPhone Safari実機のFPSは未測定。
