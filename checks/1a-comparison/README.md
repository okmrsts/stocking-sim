# 段階1aの着用比較

左に着用した脚、右に同じ20D平編みニーハイの無荷重時の基準形状を、同一の平行投影カメラで表示した。右は足先を閉じた円筒状の基準形状。縦方向の寸法は生地に沿う長さなので、足を曲がって覆う着用側の画面上の高さとは異なる。

| 表示 | 確認画像 |
| --- | --- |
| PC幅の着用比較 | [1440 × 1080](comparison.png) |
| スマホ幅の着用比較 | [390 × 844 CSSピクセル、DPR 2](mobile.png) |

無荷重側のメッシュを測ったところ、筒径48.00 mm、縦方向の材料長797.27 mmで、プリセットとの差は0.01 mm未満だった。全描画頂点で縦横の伸長率は1、縦横の張力は0。着用側の太ももの計測点では、周方向の伸長率は2.93倍、縦方向は1.09倍。これらは物性の実測校正前のモデル値。
