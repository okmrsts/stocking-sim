# 拡張ガイド

段階1aの実装と後段のデータ契約は [仕様書](SPEC.md) を参照。

- 編み組織は `src/stocking/patterns.js` と対応する設定に、レストピッチ、糸芯の周期曲線、前後関係、糸接続、伝線の依存辺を追加する。無荷重・着用・極限マクロを同じ材料座標で対照する。
- 新素材は `src/config/` に密度・線密度、弾性、破断、光学・濡れ係数を追加する。測定条件・出典と推定の区別を `docs/decisions/` に記録する。
- 他の作品では `core/cloth/` に材料座標を含むメッシュと物性を渡す。編み物の表示を組み合わせる場合は `core/textile/` へ布のフレームとパターンを渡す。脚以外の衝突面も `CollisionField` を実装できる。
- 体型の可動域、変形する高さ、軟組織の前・外・後・内の係数は `src/config/body-regions.js` で変更する。軟組織の部品を再利用するときは高さと角度からコンプライアンスと飽和深さを返すサンプラーを渡す。
- 外部の脚モデルは `.glb` とジョイント対応、衝突プロキシ、権利情報を `loadBodyModel()` に渡す。手続き生成と同じ距離・向き・単位の契約を満たす。
