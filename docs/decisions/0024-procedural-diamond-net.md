# 0024 平編みと網タイツの糸

60Dのタイツは20Dと同じ平編みのループ計算を使い、糸量、無荷重の幅、張力係数を設定で変える。20Dと60Dの糸の半径は線密度、繊維密度、充填率から求める。

網タイツは菱形に交わる2方向の糸を、布の材料座標で表す。方向ごとの糸間隔は縦横の伸長を反映する。糸の太さは糸束の設定から求めたメートル単位の半径を使う。網目が1画素に満たない距離では、画素が覆う区間で糸の被覆率を積分する。斜めの視線では糸を通る光の減衰が増える。腰と補強したつま先は平編みで表す。

網脚部の菱形は、ラッセル風の見た目と開口を扱う近似。糸束の線密度と他の物性は静止表示で使う設定値で、特定の実物の設計値を示すものではない。糸の結び方からほつれを求める処理は後続段階で扱う。[段階1bの検証](../../checks/1b/README.md)
