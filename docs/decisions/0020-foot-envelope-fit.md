# 0020 足部の包絡面と足首の曲がり

着用面を作るとき、前足部の補間、つま先の断面、布の表面にそれぞれ余裕を加えていた。余裕が重なる甲とつま先では、布が皮膚から浮いて見えていた。また、甲から足首へ曲がる区間では、別々の中心で傾けた断面が足首の前で交差していた。布が同じ場所を往復し、正面から足の側面に続く濃い筋ができていた。

甲から足首へ向かう断面は、足首の前に置いた共通の点へ扇状に向ける。断面をずらす区間は足部の設定に置き、ふくらはぎ側の水平断面へつなぐ。各断面は皮膚の形状場との交点から作る。足部の寸法と皮膚の形状は採寸に基づく。[足部の採寸と五本の足指](0019-anatomical-foot-landmarks.md)

指先の丸みをまたぐための前後方向の余裕は、指が分かれ始める位置から段階的に加える。甲の補間では余裕を小さくし、曲率が大きい足底側には粗いメッシュの三角形が皮膚を横切らないよう局所的に余裕を残す。五本の指を一つの布が包むので、指間は張った布がまたぐ。指の谷まで布を押し込むと、足指の形に沿って逆向きの接触圧が必要になる。

確認では、実際に描画する布と肌の三角形から甲の上下方向の隙間、足指側の見付け幅、先端の前後方向の余りを求めた。足首の前部では三角形の向きを皮膚の形状場の勾配と比較した。貫通の判定は布の三角形の重心を対象とする。全表面の連続判定は後続の動的接触で扱う。[計測と比較写真](../../checks/1a-foot-fit/README.md)
