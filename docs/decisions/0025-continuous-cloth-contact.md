# 0025 着脱時の布面どうしの連続判定

段階2の着脱では、着用位置と引く向きからWGSLで次の布の形状を求める。外側・内側の指定は、履き口に近い布ほど周方向に異なる距離を進める。左右は同じ動作を鏡映し、同じ軌道上に戻る。足から離れているときと着用の終点では、斜めの移動を減衰させる。

候補を画面に反映する前に、現在位置から候補位置まで各頂点が直線で動く区間を検査する。人体とは布頂点の軌跡と人体の三角形を照合する。布では、縫い目のUV重複を同じ頂点として扱ったうえで、頂点を共有しない三角形を検査する。左右は中央面を越えないことを別に確認する。

- 外接範囲は、区間の両端で同じ順序で離れている軸があれば除外できる。各端点の座標軸と斜めの投影を階層に保存し、面どうしの比較を減らす。
- 残った面の組は、面の法線、辺の外積、同一平面の分離に使う軸で検査する。時間内の分離が確かめられなければ区間を分ける。分割の上限まで判定できない候補は交差の可能性がある候補として保留する。
- 肌または布との交差の可能性があれば、着用位置と斜めの量の変更幅を半分にして再度検査する。有効な候補が得られなければ、最後に採用できた位置を表示する。
- 脱衣後に両端で断面が平行かつ深さ順に並ぶ区間では、断面間の順序で分離が分かる。通常の着脱ではCPUの判定をWeb Workerに移し、方向切り替えや一時停止の入力を処理できるようにする。

肌との判定は布頂点から人体面への交差を対象とする。布どうしの検査では頂点を共有する面の折り重なり、布の厚みによる力、任意方向の把持や腰丈の着脱は別の実装・検証対象。離散姿勢の重心検査と、間の交差だけを起こす合成テストも併用する。[連続衝突判定のベンチマーク](https://continuous-collision-detection.github.io/tight_inclusion/) · [今回の着脱の検証](../../checks/2-contact/README.md)
