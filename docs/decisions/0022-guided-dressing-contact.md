# 0022 着脱の経路と服地の接触

ニーハイの材料座標とつま先から履き口までの接続を保ったまま、着用の進行に合わせて対応する人体の断面を移す。足が入るまでは甲の前で布を寄せ、つま先が収まると足部を覆い、残りの長さを履き口の手前に寄せる。断面内で膨らませて布の列の順序を保つ。向きを法線に沿わせて膨らませた試作では、つま先付近の隣接列の間で交差を検出した。

- `dressing-input.js` が適合面上の位置・断面内の外向き方向・材料座標・レスト形状・静止着用の終点を渡す。
- `guided-shell.js` と対応する WGSL が位置と縦横の伸長を求める。位置はメートル、伸長はレスト長に対する比、張力は線形膜の推定値（N/m）。伸長を編み目の被覆率の計算に渡す。
- `swept-vertices.js` が前回の表示から今回の候補までの線分を人体の三角形に対して検査する。交差時は着用位置の刻みを半分にして再試行し、安全な候補が得られなければ最後に採用した位置を保つ。左右対称の操作は片脚の計算を鏡映する。判定は移動する布の頂点と固定した人体面の組み合わせを対象とする。
- 肌から離れた布は履き口側を支え、WGSL の固定刻みで重力、長さ拘束、床、減衰を計算する。布の中心線53点を使い、長さ方向の断面順序に下限間隔を入れて折り畳みの層を保つ。

この実装で扱うのは断面で誘導する着脱経路と、支えた布が床まで垂れる動き。任意方向への手の移動、布面の辺どうしの時間連続衝突、人体と布の連成変形は検証対象として残る。布どうしは離散姿勢の三角形の交差検査、肌との貫通は線分判定に加えて足部の面重心で照合する。連続衝突としての検出範囲は本文の組み合わせに限る。[三角形の連続衝突の研究](https://ipc-sim.github.io/C-IPC/) · [検証結果](../../checks/2/README.md)
