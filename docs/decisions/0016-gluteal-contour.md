# 0016 臀部の丸みと臀溝

決定日 2026-11-20

旧版の骨盤シェルの後方には下端があり、上腿をつなぐ位置が後ろ斜めから横一線の段に見えていた。左右の臀部のふくらみを個別の楕円体で作り、後方の骨盤表面を内側に寄せてから、符号付きスカラー場で骨盤と大腿に滑らかにつないだ。正中のくぼみと、大腿後面との境にある臀溝は別々の形状として持つ。

Si らの解剖研究では、臀溝の内側は皮下の筋膜による固定が強く、外側では固定が弱まって臀部と大腿の境界が滑らかになる。これを形状へ反映し、臀溝は内側で深く、外側へ近づくにつれて浅く消えるようにした。基準位置は産総研の青年女性群の殿溝高平均 692.3 mmを参考に、床面の位置を含めモデル座標の 694.1 mm に置いた。殿幅と殿部厚径は従来と同じ断面で照合した。[Si ら、2024年](https://pubmed.ncbi.nlm.nih.gov/37220258/) · [産総研 B17](https://www.airc.aist.go.jp/dhrt/91-92/data/gif/B17.gif) · [採寸の基準](0015-anthropometric-lower-body.md)

臀溝の最大深さ2.5 mm、左右のふくらみの半径、傾き、接続範囲は、立位の表面を手続きで近似する形状パラメーター。骨盤の表面生成で設定を共有するため、素足表示と着用表示の両方に同じ修正が入る。修正の影響は上腿で滑らかに弱め、履き口には着用計算に使う脚の断面を渡す。臀部のパラメーターは `src/config/leg-anatomy.js` の `lowerBodyConfig.gluteal` に集約した。

臀部の固定視点は画面が縦長のときだけ画角を広げる。前後比較用の1440 × 1080の画角は同じ値を使う。
