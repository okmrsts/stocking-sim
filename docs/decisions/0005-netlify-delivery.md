# 0005 静的ファイルを Netlify から配信する

決定日 2026-11-20

ユーザーの指定で配信先を Netlify の `stocking-sim` に変更する。段階0は `index.html` を静的に配信する。リポジトリの履歴・仕様書・検証記録は Git に保存する。ビルドコマンドを必要としないため、初回は配信用ファイルを手動デプロイできる構成にする。段階1以降はブラウザーから読むモジュールと静的素材も同じディレクトリ構造で配信する。

Netlify プロジェクトの作成後は、初回デプロイが成功して HTTPS ページが応答するところまでを確認する。訪問者設定は現在のチームログインを記録し、公開範囲の変更は明示された要望に従う。

- [Netlify のデプロイ方法](https://docs.netlify.com/deploy/create-deploys/)
