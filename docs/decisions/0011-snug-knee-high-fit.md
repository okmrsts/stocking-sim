# 0011 ニーハイの未着用寸法と余長を縮小

決定日 2026-11-20

段階1aの20D平編みニーハイを、着用時に足首と膝裏へ余る布が少ない寸法に調整する。未着用の胴の筒径を53.6 mmから51.0 mm、足部の基準径を42.0 mmから39.8 mmにした。縦方向の基準レスト長の比を1.014から0.974へ下げ、足首と膝裏に局所的に足す余長も減らした。筒径は円筒換算の直径、縦寸法は足部から履き口までの材料座標に沿う長さを測る。

局所の縦方向の補正、中心位置と幅は `src/config/stage1a.js` の `axialEaseZones` にまとめる。足首の余長のピークは15.5%から8.0%に減らし、曲がった膝裏に布がたまらないよう、膝周辺は14.3%の加算から2.5%の減算にする。百分率はいずれも基準レスト長への比率の加算または減算。ストッキングを履いた状態の丈を基準として、短くしたレスト形状から縦横の伸びと余りを再計算する。横シワは既存の圧縮・座屈計算から生じ、重なりは自己接触で処理する。
