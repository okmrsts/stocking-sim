# 0012 足部の接触面とニーハイの密着度を調整

決定日 2026-11-20

未着用時の胴の筒径を51.0 mmから48.0 mm、足部基準径を39.8 mmから36.8 mmにする。縦方向のレスト寸法を全域で短くし、足部用の補正を加え、足首の余長を減らす。脚側の布の基準クリアランスは0.60 mmから0.42 mmとする。布の伸び、張力、糸の間隔は変更後の寸法と着用面から再計算する。

旧版では足指の上に、手で指定した大きめの丸い断面を使っていた。前足部の各断面に対して皮膚の陰関数をサンプリングし、測った外周点の凸包を布の接触面に採用した。隣接する足指の谷を布がまたぎ、足指の根元から先端までに沿う。前足部より後ろは皮膚に対して半径方向の交点を求める方式を使い、距離に応じて接続する。

小さい足指の先を越えると断面幅が急に変わるため、近接した2断面を取り、三角形の弦が皮膚を横切りにくいよう小さな余裕を設けた。つま先を閉じる位置は、最も前にある足指の寸法から求める。布の余裕は断面の凸化・皮膚と布の隙間・メッシュの解像度で決まり、足指それぞれを分けて包む形状にはならない。

つま先の前方への張り出しと前足部幅を、皮膚と布の両メッシュに対して比較する。皮膚に対する食い込みは足部の布の頂点と三角形の重心で検査する。[撮影と計測](../../checks/1a-close-fit/README.md)
