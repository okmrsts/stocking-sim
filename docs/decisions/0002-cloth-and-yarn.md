# 0002 布の変形と糸の構造を材料座標で結ぶ

決定日 2026-11-20

ソルバーのレスト形状と現在形状を物理・光学で共用する。布面は拘束を持つ三角形、編み目は材料座標上の糸芯、破断と伝線は布面に支点を持つ糸の接続として扱う。糸芯に対する距離は現在形状の接平面で測り、拡大しても伸ばしても実寸の糸半径を保つ。編み組織の違いはストッキング側のデータで定義し、ソルバーには糸接続、材料則、拘束を渡す。

段階1から糸への対応を生成できる材料座標を保持する。段階4では損傷点の周囲で拘束と描画メッシュを同期して切り替え、破断後の荷重を更新する。全域の糸を立体メッシュで組む費用を抑えつつ、個別破断と伝線を表現する。連続体から糸への荷重配分と光学的な層順の精度は実装時に比較計測する。
