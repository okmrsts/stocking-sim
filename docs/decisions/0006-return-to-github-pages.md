# 0006 GitHub Pages への公開を準備する

決定日 2026-11-20

ユーザー指定に従い、`okmrsts/stocking-sim` の `main` ブランチのルートを公開元にする。`.nojekyll` を置き、診断用 `index.html` をビルドなしで配信する。GitHub Pages の HTTPS URL で診断ページを受け取れることが配信先確定の条件。Netlify の作成済みプロジェクトは接続・比較の記録として残す。

- [GitHub Pages の公開元の設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
