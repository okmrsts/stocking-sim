# 0010 静止着用の折り返しと局所自己接触

決定日 2026-11-20

足首と膝裏では軸方向に余る材料長を設定し、圧縮が大きいほど、WGSL の着用計算で布の軸方向が一部逆転する折り返しを生成する。曲面には同じ場所を通る別々の材料座標を持った層ができる。光学は変形後に計測した縦横の伸びを使い、表裏を描画して透過を合成する。

汎用の静止筒状布ソルバー `src/core/cloth/static-shell.wgsl.js` に、同じ縦方向の列にある非隣接の頂点と辺を比較する自己接触を追加した。材料上の前後12行を候補とし、軸方向で重なり、布の法線方向の隙間が設定距離より狭ければ、外側の層を外へ投影する。標準設定ではこの投影を別々の読み書きバッファで4回実行する。皮膚から遠ざける方向の補正で既存の着用拘束を維持する。設定した分離距離の目安は 0.42 mm。診断値は4回の累積補正量であり、層間距離の表示とは用途が異なる。

局所探索で着用状態の静止した横折れを扱う。異なる列をまたぐ任意の面どうしの衝突、着脱中の時間連続衝突判定と摩擦は後段の動力学が対象となる。仕上がりの指標として、縦方向が逆転した頂点の数、自己接触の補正が発生した点数と最大補正量を記録する。[撮影と計測](../../checks/1a-revision/README.md)

この版も標準を 22,945 計算点・45,120 三角形とする。24 mm 波長に対して標準は縦方向に約10区間取れる。2パスだった変更前から初期フィット計算が6パスに増え、別メッシュの足部も更新した。変更前の iPhone 実測の最大値 43,165 点・85,272 三角形を改修版の実機計測用の上限候補とする。改修後の30 FPS は iPhone の再計測で判定する。
