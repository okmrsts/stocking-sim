# 0023 腰丈の3種類と布メッシュの境界

段階1bでは20D平編みパンスト、60Dタイツ、網タイツの3種類を追加する。脚部には既存の静止WGSLの異方性の張力・縦圧縮・足の形へのフィットを使う。ウエストから股下までは骨盤の形状場の外側を取り、左右の脚の布と縫合する。形状としては両足先が閉じ、一続きの布で、ウエストだけが開く。編み目を一周でつなぐため、表示メッシュではUVの切れ目の頂点を複製する。

腰部は静止着用の近似で、形状場の断面と法線、無荷重の腰回りから局所の周・縦の伸長を推定する。脚との接続付近では、足側の伸長と材料座標を引き継ぎ、上へ進むにつれて腰回りの材料座標に移る。ウエスト帯は糸量を増やした設定にする。腰部の接触圧と自己接触、腰丈プリセットの着脱と無荷重比較は後続の検証対象。

人体曲面と布を両方表示する負荷を抑えるため、骨盤の布は6.4 mm刻みの格子から生成する。脚との縫合部から腰へ向けて外側の余裕を滑らかに増やし、股下の曲率で皮膚と交差しないか布面の重心で検査する。比較写真と速度の測定条件を記録する。[段階1bの検証](../../checks/1b/README.md)
