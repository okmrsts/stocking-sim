# 0021 静止着用時の足首の細かいシワ

旧版では足首にも他部位と共通の24 mm周期を使っていた。足首は着用時に余る丈を減らし、縦方向に圧縮した場所だけに浅い波が生じるようにした。周方向で位相を少しずらして、シワが輪のように一周でそろうのを抑えた。布面が弱い圧縮を受けたときの波の高さは、レスト長と接触面での距離から計算する。

ニーハイ組み立て側は、細かい座屈を使う区間を点ごとの重み `restProperties.w`（0〜1）として渡す。汎用の静止 WGSL 側ではこの重みで細かい座屈と折り返しを補間する。細かい波の目安は9.5 mm、モデル上の高さの上限は0.40 mm。粗いメッシュでは周期を行間隔の3.5倍以上にして、メッシュの粗さによる縞を抑える。大きな圧縮が起こる他部位では従来の折り返しと自己接触を引き続き使う。

これらの数値は、立位で着用した20Dの静止モデルに用いる調整値。薄い膜のシワの間隔や高さは曲げ剛性と荷重・形状の影響を受ける。実際のニーハイの見え方も編み地、サイズ、足首の角度で変わる。後続の動的な計算で、曲げと圧縮を拘束として求める。[薄膜の座屈理論](https://doi.org/10.1103/PhysRevLett.90.074302) · [計測と比較写真](../../checks/1a-foot-fit/README.md)
