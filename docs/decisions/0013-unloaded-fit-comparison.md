# 0013 着用と無荷重時の基準形状を同縮尺で比較

決定日 2026-11-20

段階1aの着用表示では、布を脚の接触面に配置し、着用後の縦横の距離を無荷重時の距離で割って伸長率を求める。その伸びから張力を推定し、軸方向の余りから座屈と布の自己接触を計算する。動的に履き上げる過程と、実物の応力・伸び測定による物性の校正は今後の工程。

左右比較の右には同じプリセットの無荷重時の基準形状を表示する。着用計算と共有するレスト半径、材料座標、補強の分布から、つま先の閉じた円筒曲面を生成する。縦方向の実長を保つよう、半径が変わる箇所では縦座標の増分を調整する。縦横の伸長率は1、張力は0とする。足型や重力により垂れた形状は動力学で扱う。

両方を同じ平行投影カメラで描画し、同じ長さが同じ画素数に写るようにした。左右の位置は画面上で決まり、回転してもモデルどうしが重なりにくい。既定の画面は「着用比較」とし、「全体」と各拡大視点で着用側を単独表示できる。[比較画像と検証](../../checks/1a-comparison/README.md)
