# 操作ガイド

## 段階0

PC とスマートフォンの対応ブラウザーで診断ページを開く。色の付いた三角形が出て「WebGPU 描画成功 · 検証エラー 0件」と表示されたら成功。API・アダプターの非対応や初期化・シェーダーの異常時はステータスと詳細欄を確認する。

## 後段の操作予定

| 操作 | PC | スマートフォン |
| --- | --- | --- |
| モード・道具の選択 | 画面内の操作バー | 下部ツールバー |
| 視点 | 視点ツールでドラッグ、ホイールで拡大 | 視点ツールでスワイプ、ピンチ |
| 摘む・切る・濡らす | 道具を選び、布をクリックまたはドラッグ | 道具を選び、布をタッチまたはスワイプ |
| 設定 | 設定ボタン、閉じるボタンまたは Escape | 設定シート、上部の閉じるボタン |
| 比較・乾燥・リセット | 対応モードの操作バー | 対応モードの下部ツールバーまたは設定シート |

設計ではプリセットまたは設計項目を編集する。着脱では履く／脱ぐと比較表示を選ぶ。着用テストでは道具・確かめ表示・全体／マクロを切り替える。操作が使用可能になる順番は [仕様書](SPEC.md#6-モードui段階) を参照。
